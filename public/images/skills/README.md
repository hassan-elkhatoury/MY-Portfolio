# Technology logos

SVGs vendored from [Devicon](https://github.com/devicons/devicon) at commit `6a37858047b0e8d9c9c0e68f4a071fc410652e89`. Original variants, unmodified. See LICENSE.txt for the MIT license. Brand names and logos remain the property of their respective owners; their appearance identifies technologies used in this portfolio.

Docker uses Devicon's unmodified plain SVG variant from the same pinned commit for a simpler silhouette. REST, SQL and general engineering concepts use code-rendered pictograms, since they do not represent individual product brands.

`googlegemini.svg`, `openrouter.svg`, `xampp.svg`, and `zod.svg` come from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/30053a0f492fd192740ad001031b3091be060986/icons), pinned at commit `30053a0f492fd192740ad001031b3091be060986`. Their paths are unchanged; the root fill uses each brand's color from that commit's `data/simple-icons.json`. See SIMPLE-ICONS-LICENSE.md (CC0) and ZOD-LICENSE.txt (the Zod logo's MIT license).

Sources recorded by Simple Icons: [Google Gemini](https://gemini.google.com), [OpenRouter](https://openrouter.ai), [XAMPP](https://apachefriends.org), and [Zod](https://github.com/colinhacks/zod/tree/ff89187172ac6aa4a6264592980d1628ee785242/logo).
